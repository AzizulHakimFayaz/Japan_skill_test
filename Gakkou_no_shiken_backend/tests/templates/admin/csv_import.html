Instructions for Google Sheets & Excel Users:
  1. Choose Template: Click JFT Sample CSV for standard JFT-Basic 4 sections (script_vocab, conversation, listening, reading), OR SSW Prometric Sample CSV for 2-phase Specified Skilled Worker tests (audio Phase 1 & occupational Phase 2).
  2. Typing Questions (SSW): Set type to typing or audio_typing. Put the accepted correct answer(s) (e.g. いらっしゃいませ or irasshaimase) in option_1, option_2, etc.
  3. AI Audio Generation: Add an audio_script column with dialogues like [Nanami], [田中さん、今週の日曜日に...], [Keita], [日曜日ですね。...] to automatically generate multi-speaker Japanese audio!
  4. Shared Passages / Audio: Use the group_title column (e.g., "Reading Passage 1") to group multiple questions under the same image or audio clip!
  5. Correct Answer: Set correct_option to 1, 2, 3, or 4 matching the correct answer choice.
  6. In Google Sheets: Click File > Download > Comma-separated values (.csv).
  7. Select your target Test below and upload the CSV file!
